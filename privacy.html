Chính sách quyền riêng tư – Chat Alert Bot

Cập nhật: 20/11/2026

1. Phạm vi

Chat Alert Bot là công cụ cá nhân, chỉ chủ tài khoản sử dụng. Công cụ gửi báo cáo công việc quá hạn vào nhóm Google Chat mà chủ tài khoản là thành viên.

2. Dữ liệu Google được truy cập

Công cụ chỉ yêu cầu quyền https://www.googleapis.com/auth/chat.messages.create để tạo tin nhắn. Công cụ không đọc tin nhắn, không đọc danh sách thành viên, email, danh bạ hay bất kỳ dữ liệu nào khác.

3. Lưu trữ

Mã truy cập (OAuth token) chỉ được lưu trên máy tính của chủ tài khoản. Không có máy chủ trung gian, không lưu trữ trên đám mây, không thu thập dữ liệu phân tích.

4. Chia sẻ

Không chia sẻ, bán hay chuyển dữ liệu cho bất kỳ bên thứ ba nào. Việc sử dụng dữ liệu nhận từ Google API tuân thủ Google API Services User Data Policy, bao gồm các yêu cầu Limited Use.

5. Thu hồi quyền

Có thể thu hồi quyền bất cứ lúc nào tại myaccount.google.com/permissions và xoá file token trên máy.

English summary: Chat Alert Bot is a single-user personal tool. It only requests the chat.messages.create scope to post messages to a Google Chat space the owner belongs to. It does not read any data. Tokens are stored only on the owner's computer and are never shared with third parties. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
